# If-else ex02

Para o exercício 02 If-else decici testar aprendizados em aula e tambem o random, pois ficou em falta no meu trabalho anterior, e assim conseguiria trabalhar um pouco com o mesmo agora. 
O cógigo divide o ecrã em duas aréas distintas, o que cria uma experiência visual diferente para cada lado do rato. Do lado direito surgem formas orgânicas que criei com as elipses, que originam formas mais arredondadas, e do lado esquerdo confrome o corsor aparecem formas geométricas como quadrados e retângulos. Criam assim um contraste entre ambos os lados.
Para desenvolver o código utilizei referências do p5.js e tambem AI para conseguir defenir em que lado é que iriam aparecer as formas que já tinha feito anteriormente e para que ambas não se misturassem.
